# T10 提现页面与演示

## 背景
ADR-0006 补充第 8 节；AC-7.19；现有前端（退款页面、纠错页面、总览）和 Playwright 用例（照着写）。依赖 T03–T08。

## 范围
1. 提现列表、详情页（状态时间线、银行请求号、尝试列表、出账/退回流水、分录、差异链接）；总览加提现在途、free_cash；提现表单（金额、业务编号，显示 409 原因）。
2. 纠错详情能展示第五种类型。
3. 演示脚本（沿用现有演示/E2E 夹具方式）按 ADR 第 8 节；Playwright 用例 AC-7.19：页面 `UNKNOWN → PAID`、银行请求号、流水行、余额正确、`/sim/bank/payments` 只有一笔。
4. 前端单测覆盖金额显示（商户欠款、free_cash 为 0 时的提示）。

## 可改范围
`frontend/**`、E2E 夹具与脚本、只读接口里页面缺的小字段（只增不改）、对应测试。

## 完成标准
按 `_common.md` 第 5 条（`npm run check` 与 `npm run test:e2e`）；本地提交（`Task: T10`）。
