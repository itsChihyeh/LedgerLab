# ADR-0012 时间契约

状态：已采纳（P0）。来源：复核 I5。细则见 design/contracts.md 第 1 节。

## 决定
区分 `occurred_at`（外部发生）、`received_at`（我们收到）、`recorded_at`（我们提交）；签名时间只用于防重放。业务日按 America/Toronto 由 `occurred_at` 划分；对账运行记截止时点；所有“现在”来自注入的 Clock。

## 理由
迟到的 webhook、跨日的结算单行、按日对账，都要求“发生在哪天”和“我们哪天知道”分开；只存一个时间，跨日差异就无法解释。

## 后果
每张业务表多两到三个时间列；测试可以快进时钟复现跨日和老化。
