# ADR-0015 批次结算记成一个分录

状态：已采纳（P0）。

## 决定
一个批次 = 一个 `BATCH_SETTLED` 分录，5 条 posting（批次净额恒 > 0）：借在途 N、借待结算 F / 贷应收 N+F；借待结算 G−F / 贷可用 G−F。

## 备选
拆成“处理方结算”和“商户转可用”两个分录：每个分录更单纯，但两者必须同时成立，拆开就要靠事务保证，审计时也要拼起来看。

## 后果
`source_key = batch:{batch_id}:settled` 一个键就保证整批只记一次。

## 补充（2026-10-21，开工前审查）
- 删去“5 条 posting（批次净额恒 > 0）”的固定条数：净额 > 0 不代表手续费、毛额都 > 0。只有失败打款退回的批次（G = F = 0）会产生 3 条 0 元 posting，违反 INV-1。
- 改为：一个批次仍是一个分录；按模板生成 posting，**省略金额为 0 的**，`posting_count` 按实际条数封存（2～5 条）。见 money-model 样例 H。
