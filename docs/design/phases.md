# 阶段计划

P0 设计稿 v0.2，2026-10-21（同日开工前审查修订）。按依赖推进，不对应日期；每个阶段以 [验收条件](../acceptance-criteria.md) 里对应的条目全部通过为完成标准，前面阶段的测试必须继续通过。每条 AC 只属于一个阶段。页面不等到最后：每个阶段做完都有对应的页面能演示。

## 简历的两条线（立项复核结论，按新阶段更新）

- **可以写上简历的最低线**：P1～P4，加基本页面和干净环境可复现。
- **“足够好”、之后不再主动扩张的线**：再加 P5（提现恢复、三方对账）、P6（真实 Stripe 沙箱）、P7（部署、演示页、性能基线、演示视频）；有真抓到过缺陷的模型测试或并发测试记录。AI 岗再加 P8 的诚实评测。
